# SCOOP RUNNER

Endless journalism game built with Grok.

**Chase the story. Beat the deadline.**

Collect scoops. Dodge lawsuits, fake news, and deadlines.

## Play

Open `index.html` in a browser. Tap / click / press Space to jump.
